# C + Native Relational Self-Flow 问题诊断

日期：2026-10-28。依据实际训练日志、故障快照、配置和12K Kodak24评测。本文不启动训练、不修改权重，也不把机制上的疑点写成已证实的失败原因。

## 结论与边界

已证实两件事：本次训练在FP16原生student前向反复出现非有限值，无法稳定继续；目前唯一新增的完整12K评测没有明确超过同step纯C。前者是已发生的稳定性故障，后者只是早期收益尚未体现，不能合并成“SF已经证实无效”。

SF关系loss明显下降，但不能据此断言恢复了压缩丢失的信息；也不能据此诊断特征塌缩、teacher无内容、或梯度冲突。旧实验的专用预测头P吸收收益问题不直接适用于本版，因为本版已去掉P。

## 实验身份与实际实现

- 仓库：`/data2/ls/code/DiT-IC-c-native-relational-sf-20261027`。
- 提交：`279867bed45cdb6abbbc93f9d22bf6321b148671`，方法`native_relational_v1`。
- 起点：指定纯C 10K checkpoint，之前已有50K latent warmup；没有继承旧SF权重。
- 512输入，双卡各batch4，积累1，有效batch8。未启动本机纯C训练。
- 主损失：`4*MSE + LPIPS + DISTS + 0.1*base + beta(qA)*R_native_total`；repaired-latent损失为0。
- 六档q为`[0,.2,.4,.6,.8,1]`，beta为`[16,8,4,2,1,.5]`。主qA逐更新独立随机，qB独立随机，同一更新全batch共用一对q。
- SF从10K开始，2K步线性ramp，12K达到权重1；两个有效视图取平均，并非每个视图都另加权重1。
- teacher仅含EMA DiT前20层及必要条件投影，不含codec或VAE；EMA decay=.999。
- 当前共享codec在qA、qB分别重新分析同一干净latent得到cA、cB；qB构造无梯度。cMix的75%局部cell来自cA、25%来自cB，所有通道共同选择。
- 正式student：cA完整经过28层、原C修正与VAE，原生RD；同一次前向读取H8做原生SF，SF梯度可以进入codec。
- 混合student：detach(cMix)只经过共享前8层做SF，无D_mix、无额外图像读出，梯度只进入共享前缀。
- teacher接收名义较高q对应的完整cHigh，输出H20。两种student都对齐其空间关系。
- 关系：`Hc = H - mean_tokens(H)`；`r = offdiag(Hc @ Hc.T)`；`d = 1-cos(rS,stopgrad(rT))`。Gram与cosine已显式FP32计算。
- 原生/混合先后反向后只做一次全局梯度平均与optimizer更新。没有P、辅助跳层出图、额外质量conditioner。
- 部署只有原生C路径和原生packet。混合训练视图增加计算，不产生一条被算作低码率成绩的混合码流。

## 已发生的数值故障

最后完成更新13643，从C10K实际新增3643步。首次故障快照记录已完成step13640；之后三次FP32重放各成功完成一个更新，但切回FP16后下个更新继续故障。2026-10-28约02:10（北京时间）监督器达到三次自动恢复上限后退出，暂停checkpoint保存在`joint/paused.pt`。没有OOM记录。

最后故障快照，两张卡均显示：

| 位置/状态 | 记录 |
|---|---|
| 主模型保存状态 | `model_state_finite=true` |
| 干净latent | finite，rank0最大绝对值7.8466，rank1为6.7168 |
| codec输出coarse | finite，rank0最大绝对值7.1693，rank1为5.8489 |
| base与rate loss | finite |
| teacher H20空间标准差 | finite，约12.43 / 12.28 |
| student H8空间标准差 | NaN |
| 修复latent与最终图像 | 非有限 |
| 图像MSE、LPIPS、DISTS | NaN |

因此，student原生H8之前或H8输出处已经发生异常；问题不是到SF Gram/cosine或图像指标才首次产生。teacher目标有限也不等于teacher对重建有益。

该故障发生在backward和optimizer更新前。GradScaler只缩放反向loss，不能挽救前向已经产生的NaN。增大cosine eps也不能修复输入特征已经损坏的问题。相同待重放批次用FP32能够完成训练更新，是精度相关故障的重要证据；仍未定位首个非有限算子，不能把某个具体attention投影、MLP或归一化认定为根因。

已有精度修复包括FP32自注意力收缩/归一化、cross-attention、MLP与caption projection；仍有AMP投影及其他操作。需要逐算子复现后才能确定还缺哪一处。

正常训练日志的已记录梯度范数最大约1.228，未出现`amp_skipped_update`消息；这不支持直接归因为典型的大梯度爆炸，但日志不是每步记录，也没有SF/RD分项梯度。

## 真正压缩结果

新增完整评测只有12K，共Kodak24×六档；以正式部署EMA出图，全24张实际packet含side/header计费，packet解码与forward一致。对照为用户提供的外部纯C CSV，同step比较。

共同总bpp区间约`.017629–.094940`，在log(total bpp)上分段线性插值，不外推；101个等log码率点均值：

| 指标（SF − C） | 全共同区间 | 低码率三分之一 | 高码率三分之一 |
|---|---:|---:|---:|
| PSNR（越大越好） | -.008645 dB | -.012217 | -.008287 |
| LPIPS（越小越好） | -.0000447 | -.0001435 | +.0003034 |
| DISTS（越小越好） | +.0003152 | +.0013296 | -.0002424 |

同q六档bpp平均增加.1354%，最低q增加.5415%，没有观察到大幅多发bit。同q平均RD loss增加约.1480%。目前更接近持平和微小混合变化，未表现为一致收益。

限制：只额外训练2K步且SF刚完成ramp；训练loss对应raw student，而正式评测用EMA；单seed，未做逐图显著性分析；外部C为BF16，本机V100为FP16 AMP+FP32修复。不能把这些微小差异全部归因于SF，更不能推导出20K后也必然没有收益。

## 对下一版设计最有用的机制疑点

1. **对齐的是空间关系，尚未证明它包含当前码率真正缺失、且正式解码会使用的信息。** 关系loss不直接要求恢复量化误差、纹理或所需的修正。这是目标与压缩任务之间的未验证环节，不是已测得的梯度冲突。

2. **关系指标存在较大的不敏感空间。** 在非退化且忽略eps影响时，给全图所有token加同一通道向量会被中心化消去；统一缩放和通道正交变换保持Gram方向。因此很低的关系loss不能控制特征幅度、通道坐标或保证原C后半段能利用该表示。尺度不敏感不等于这个loss主动奖励尺度增大；是否出现实际的退化/捷径尚未测量。

3. **局部双质量任务可能容易，且未直接检验受损局部是否被恢复。** 混合与原生都对齐全图关系，没有单独记录被替换区域、q差距与局部细节的变化。启动预检同一批图的原生/混合loss约.06855/.06811，训练中两者也经常接近；这只是任务差异弱的线索，不能证明网络忽略mask。当前缺少关闭mixed分支的同起点短对照，无法判断额外prefix8是否有贡献。

4. **原生视图与混合视图承担不同任务。** 正式路径确实同时重建与对齐，旧版“P单独吸收收益”的问题已消除；但混合输入只做前8层的关系学习，没有生成重建监督。它学到的局部补全能力是否存在、是否被原生重建复用，仍要验证。这与“同一个混合student输入同时承担生成和对齐”并非同一个实验，不能声称完整复刻原Self-Flow。

5. **两档独立抽样并不意味着每次原生student都比teacher输入更差。** 六档均匀独立时，qB>qA的概率为15/36（41.7%），qB=qA为6/36（16.7%）；剩下qA>qB时原生student与teacher输入相同，而混合视图25%局部被更低q替换。这个安排保持了主C的q分布，但“跨码率补缺”和“同输入浅深层一致性”混在一个平均loss里。它们的收益未分别测量。

6. **高q是更多信息的输入，不是逐图/逐局部正确的修复答案。** 预检证实初始H20关系有内容：student对正确目标约.06855、对错图约.33937；但没有证明这种关系对正式压缩重建有增益。最新13643权重的正确/错图/空间打乱诊断未完成，不能沿用旧P辅助读出的失败数值来断言本版teacher无效。

7. **teacher只有DiT做EMA，视图输入来自正在更新的当前codec。** 即便teacher权重变化平滑，它接收的cHigh仍会随codec改变；目标分布稳定性未测量。这不意味着一定要加EMA codec，只说明不能把“EMA teacher”自动等同于固定可靠目标。

8. **SF梯度已经能进入codec，连接存在不等于优化方向正确。** 启动实测原生SF对g_a/g_s/router梯度范数约.2618/.4446/.0461，mixed不进入codec，符合实现。还没有测同q、同图下SF相对RD梯度的量级、方向和实际编码分配改变。不能继续把“梯度能传到前端”当成压缩收益的充分证据，也不能据此认定权重1一定过大或过小。

## 下一版应回答的问题

- student实际用于出图的那次前向，是否必须处理局部双质量输入？如果保留原生/混合分工，新增mixed计算具体训练了什么，如何测得其独立贡献？
- teacher监督的对象，如何既允许不同码率所需的不同修正，又保留对当前缺失信息的约束？不应把“更像高q深层特征”直接当作“当前压缩恢复得更好”。
- 对齐指标降低时，是否仍保留内容区分、局部质量敏感性及受控的激活尺度？这些先做诊断，不自动变成一串新loss。
- 相同固定输入上能否连续稳定更新，且正式单码率packet/RD路径确实获得收益？训练稳定与压缩有效需要分别验证。
