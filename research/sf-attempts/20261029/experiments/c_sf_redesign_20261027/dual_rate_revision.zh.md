# 保留最初双码率 Self-Flow 的修改建议

2026-10-27。按用户最新要求，以最初的双码率局部混合为起点。本文是当前推荐方向；同目录 `design.zh.md` 中同一码流局部加噪的视图构造暂作为另一候选保留。本文未实现、未启动实验，也没有验证收益或显存。

## 保留的机制

对同一图像与裁剪，独立均匀抽取六档中的 q_a、q_b，分别得到完整的解码 latent c_a、c_b。空间 mask 约 25% 选择 B，其他位置选择 A，每个位置全部通道一起选择：

`c_mix = where(M, c_b, c_a)`。

质量图同步混合。两档不排序，所以被 mask 的位置可以更清晰也可以更模糊；同档配对也保留。Teacher 读取统一的较高质量视图 `c_H`，使用 EMA 与第 20 层特征。Student 仍使用第 8 层向 teacher 第 20 层的完整表征做 cosine 预测。

当前 precision-v2 的 g_a 受 q 条件控制，A、B 必须分别调用分析与解码，不能把同一分析结果换个 q 重量化，也不能直接混合不同分析坐标中的预量化符号。混合只发生在同坐标的解码 latent 上。

## 修改一：原生主 RD 分支覆盖全部图像

全部图像的主分支均按 q_a 走完整原生 C，正常端到端更新 codec 与后端：

`L_C = beta(q_a) * R_a + 0.1 * base_a + D411(x_native, x)`。

其中 `D411 = 4*MSE + LPIPS + DISTS`。R_a 对应 q_a 的真实原生编码；不把混合视图说成合法的混合码流，不给它编造主码率。B 视图仅用于训练辅助任务，不能把它的比特当作免费部署信息。

辅助路径中的 A、B 输入均 detach，第二次 codec 分析/解码不带梯度。这样取消了“受扰视图改变主量化任务”的路径；主 RD 的端到端联合适应仍可能间接改变码率，不能保证 bpp 固定。

## 修改二：让对齐特征接受实际图像重建检验

辅助 student 的前 8 层接收 c_mix。小 P 预测完整深层特征 H_P，cosine 目标为 stopgrad(H_T20)。此外，将 H_P 当作辅助路径的第 20 层入口，运行共用 C 第 21–28 层、输出层、C scheduler 和 VAE：

```text
原生 c_a ── Student 完整第1–28层 ── C更新/VAE ── 主重建

混合 c_mix ── 同一Student第1–8层 ── P ── H_P
                                           ├─ cosine ← EMA Teacher20(c_H)
                                           └─ 共用21–28层/C更新/VAE ── 辅助重建
```

辅助重建的 scheduler 基底必须是 c_mix 本身；不能借用 teacher 的 c_H 作为残差基底，否则图像监督会旁路获得 teacher 的额外信息。

这条辅助预测路径跳过第 9–20 层，但部署仍使用原生完整 C。它是带任务监督的浅深层学习，不是在主路径叠加归一化特征差。P 的幅值必须在读出时明确处理并监测，不能把 cosine 对方向的约束当作原始特征幅值已正确。

完整 teacher 特征来自不同质量条件，直接塞进混合输入的尾部未必有用；尤其 C 更新的输入基底与 teacher 不同。因此必须在对应 student 质量条件和 c_mix 基底下检查目标的可解码性，不能声称“换成真实 teacher 特征必然更好”。若连 teacher 特征本身在该读出下都无内容贡献或明显不兼容，这个目标就不应直接长训。

## 修改三：控制辅助梯度，避免额外分支替模型完成任务

辅助图像 loss 与 cosine loss 更新 P 和共享 student 前 8 层的可训练参数。辅助路径的尾部及 VAE 采用当前 C 的冻结权重读出，对 H_P 保留梯度；尾部/VAE 的权重由主原生 RD 分支更新。不能用 no_grad 包住读出，否则图像监督无法回到 P。

小 P 保持原版量级，避免变成一套独立的强解码器。仅 P 收敛、仅辅助重建改善，都不能证明完整原生 C 有收益。

初始建议：

`L = L_C + ramp * 1.0 * [L_cosine + D411(x_aux, x)]`。

此处 SF=1 是整个新辅助目标的外层权重；它与旧 NLL 的 1 不等价。新增辅助图像重建也改变了监督总量，后续需要去掉 cosine、保留同样辅助重建的对照，才能区分 SF 对齐与额外任务监督。

## 质量条件不能隐含省略

最初实现已把逐位置质量图用于 student 的 token 条件。当前纯 C 的 SANA 路径没有该模块。要保留最初机制，应显式增加从零初始化的质量条件适配，并让它在主原生与辅助混合路径中使用一致语义；主路径与部署都使用由已有 q 生成的统一质量图，额外 mask 仅用于训练混合。

Teacher 的质量条件随 EMA 同步。辅助尾部使用 student 混合质量图；不能把 teacher 的高质量条件伪装成 student 可用的条件。新质量模块本身可能带来收益，需要在方法说明和消融中单独承认，不能把所有改进都算作 SF。

## 训练与验证

建议从用户提供的纯 C 10K checkpoint 新建分支，保留源 C 的 optimizer/LR/EMA 续训状态，新增 P、质量条件和 teacher 单独初始化。P 先做冻结 C 的短初始化检查；主更新开始后约 2K 步将辅助权重从 0 升到 1。q_a 保持原生六档均匀抽样，q_b 独立均匀抽样，不先限制相邻档以免破坏原版的信息跨度。

每卡 local 4、积累 1，有效 batch 8，辅助任务抽取其中一半图像；主辅顺序 backward 后一次 optimizer step。显存不足才改为每卡 2、积累 2。新增读出的输入梯度、双 codec 视图及质量条件都需要实测。

前置验证应覆盖：原生 C 的初始化前向等价；质量条件一致性；混合编码视图合法性；teacher 特征正确/错图/空间打乱对照；辅助对 prefix/P 的梯度存在且对 codec/冻结读出参数为零；真实总 bpp 下的低高码率原生重建。先用短实验判断是否值得继续，不用对齐 loss 或辅助重建代替部署评测。

收益假设：跨码率局部预测提供上下文学习压力，图像读出把它限制在 C 实际可用的表征上，原生主 RD 负责部署任务与比特成本。该假设尚未被实验验证，不能保证高低码率同时改善。
