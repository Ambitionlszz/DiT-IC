# 从原版 Self-Flow 重新设计 C + SF

2026-10-27。状态：方法设计与代码审计，尚未实现、尚未切换训练，显存与收益未验证。

推荐方向：恢复原版的完整特征预测，把辅助预测接到 C 的图像解码任务；局部不对称发生在同一码流的训练视图上，主率失真分支始终使用原生码流。

## 1. 这次失败能支持什么结论

当前实现、权重 1 的 18K Kodak24 评测，对比用户提供的同一步纯 C 表格：同 q 平均总 bpp +3.472%，主 RD loss +1.387%；在重叠总 bpp 区间做 log-bpp 线性插值，平均 PSNR -0.103 dB、LPIPS +0.002987、DISTS +0.000836。没有看到整体压缩收益。跨机器精度和数据顺序不同，这些数据不能单独证明全部差异由 SF 引起。

19K 训练记录：SF target RMS 0.001522、prediction RMS 0.000719、预测 std 0.0500008，已经接近 std 下限 0.05。日志 SF loss 为 -1.497561。

代码用 Gaussian NLL 拟合两个归一化 teacher 特征之差。参与比例为 0.5，日志还没有除参与比例。因此零残差、最小方差时，该日志的理论值为：

`0.5 * 0.5 * log(0.05**2) = -1.497866`。

当前数值只比它高约 0.000305。它说明训练目标已经接近一个很容易的零残差解，不能用来证明学会了有用的语义修复；也不能据此断言整个 backbone 已经坍塌。尚未检查 teacher 特征的跨图片、空间方差及其有效维度。

还有两个已确认的机制问题：

- 当前用 `erase_mask` 把 router 分配码置零，再对整个分配图重新中心化。它并非只降低被选位置的质量，未选位置的量化步长也会变；主重建与主码率都随这种训练扰动改变。
- SF replay 对 coarse 与 delta 做 detach。因此不存在“SF 梯度直接推动编码器、router、g_s 多花码率”的路径。码率恶化可能来自改过的主 RD 任务及其共同适应，具体归因尚待受控验证。

进一步确认了扰动对编码表示的一个不应有的依赖。分配的定义是 `allocation = (2/7) * (codes - mean(codes))`：在合法取值范围内，所有 codes 一起加减同一个常数，不改变物理量化步长。例如，四个位置全为 4 与全为 0，原生 allocation 都是全 0。但把第一个位置置 0 后，全 4 的 allocation 变成 `[-6/7, 2/7, 2/7, 2/7]`，全 0 则仍为全 0。同样的原生量化状态，当前增强的难度可以完全不同，甚至彻底消失。

这是已由代码公式与数值例子确认的设计缺陷：不对称任务可以被与原生解码无关的码值偏移削弱。它是否就是本次训练变化的主因还没有证明。日志的分配直方图记录的是擦除后的 codes，不能直接当作原生 router 直方图；后续诊断应同时记录两者。

旧方案还假设“归一化特征差 × 当前 RMS”是可以加入第 20 层的有用修正。10K 的 oracle 检查中，直接注入真实目标也没有改善任何已测样本的 D411。这个假设当时没有得到实验支持，不应再靠扩大权重来挽救。

## 2. 从原论文保留什么

[Self-Flow 原论文](https://arxiv.org/html/2603.06507v1)使用局部双噪声 student、较干净的 EMA teacher、浅层对深层的 cosine 表征预测，并同时训练生成任务。其目标是 teacher 的完整表征，不是两个表征相减。论文也报告：扰动方式和训练推理分布是否匹配很重要。

这里保留浅深层 8→20、EMA、局部信息不对称和重建任务。C 没有原论文的连续 flow-matching 训练路径，因此下面是受 Self-Flow 启发的压缩适配方案，不能声称严格复现原论文，也不采用其 FID 收益作为本系统的效果保证。

## 3. 一份真实码流，两种训练视图

每张图只选择一个原生 q，按现有 precision-v2 编码器分析、量化并计算一次主码率，得到解码后的 codec bottleneck `y_hat`、实际量化步长 `delta`，以及原生 C 输入 `c = g_s(y_hat; delta)`。

Teacher 读取原生 `c`。辅助 student 在已经解码的 bottleneck 上构造一个额外视图：

`y_aug = y_hat.detach() + M * delta.detach() * u`

其中 `u ~ Uniform(-0.5, 0.5)`，`M` 在空间上选择约 25% 的 coding cells，同一 cell 的所有通道采用同一个“是否扰动”标记。用同一组冻结读出的 g_s 权重得到 `c_aug`；g_s 的 condition 仍为这份原码流的 delta。

这是一个初始候选扰动：尺度来自实际量化步长，单位是 codec bottleneck 的单位；不能把 delta 直接加到尺度不同的 SANA 输入上。它不是重新发送的码流，也不是原码流真实量化误差的精确采样。原码流的符号、hyperprior、router、量化步长、主 rate loss 均不因此改变。

两种不对称分别是：student 内有原生与扰动位置；teacher 用完整原生视图、EMA 权重和更深的第 20 层，student 用受扰视图和第 8 层。Teacher 的优势来自本次训练中更完整的观测及深层计算，不额外借用高码率细节。

选择同一码流 teacher 是本方案的研究取舍，并非高码率 teacher 必然无效。它先检验“如何更好利用已发送的信息”，避免把“学会解码”与“模仿未发送的细节”混为一个任务。低码率的细节恢复上限仍然存在。

原生主分支对全部图像保持正常 C 重建，所以模型持续在实际部署输入上训练。局部扰动只出现在辅助视图；不能用辅助视图计算第二份混合 bpp 或把两份假想码率相加。

## 4. 最关键的修改：预测的表征必须能够重建图像

仅恢复 `cos(P(h8), h20_teacher)` 还不够：小 projector 可能学会跨层映射，但实际解码没有明显变好。因此添加一个训练时的读出路径，使用 C 已有的第 21–28 层、输出层、C scheduler 和 VAE decoder。

```text
原生 c ── C 第 1–28 层 ── 原生 C 更新 + VAE ── 主重建图
   │
   └──── EMA Teacher 第 1–20 层 ────────────── H_T
                                               ↑ cosine
局部扰动 c_aug ── Student 第 1–8 层 ── 小 P ── H_P
                                               │
                            共用 C 第 21–28 层、输出层
                                               │
                                原生 C 更新 + 共用 VAE
                                               │
                                          辅助重建图
```

P 预测完整第 20 层特征，辅助路径替换它自己的第 20 层入口；不把 P 的输出当修正再加到主分支第 20 层上。这样特征有明确的解码坐标，而不是把单位方向之差猜测为正确的加法向量。

辅助路径的 scheduler 残差基底使用原生 `c.detach()`，不是 `c_aug`。这样辅助任务是预测这份真实码流所需的修复，而不是额外训练模型撤销人为加入的噪声。图像目标始终是原图 x。

为明确读出的尺度，可用 teacher 第 20 层整张图的单个 RMS 标量对 P 输出做全局 RMS 匹配。不能传递逐位置 teacher 幅值图作为捷径。所有统计都 detach；这是训练辅助路径，不是部署时的条件。P 的非零输出须保持 FP32 归一化，并监测其原始 RMS，避免仅靠幅值爆炸改变读出。

SF 对齐使用原版 cosine 形式 `1 - cos(H_P, stopgrad(H_T))`，按全部 token 平均。最先保持这一简单版本；不叠加手工边缘图、显著性图、区域难度权重或可学习方差。跨图片错配、空间打乱对照负责检查任务是否真有内容辨别能力。

## 5. 损失与梯度边界

定义 `D411 = 4*MSE + LPIPS + DISTS`，主目标维持：

`L_C = beta(q)*R_native + 0.1*base_NMSE_native + D411(x_native, x)`。

建议辅助目标：

`L_SF = mean_tokens(1 - cos(H_P, stopgrad(H_T))) + D411(x_aux, x)`。

`L = L_C + ramp * 1.0 * L_SF`。

这里必须讲清楚：SF=1 指整个辅助目标的外层权重。它与旧版 Gaussian NLL 的“1”不是相同的梯度尺度。辅助目标包含一次图像重建监督，因而不是只替换一个对齐 loss 的实验。没有新增 repaired-latent loss，base 仍只定义在原生 coarse 与 clean latent 之间。

辅助目标只在每步抽取的半批原有图像上计算，按参与图像均值归一化；参与子集已经求均值时，不再额外乘 2。它们不是额外独立采样的训练图像。

| 参数 | 主 C loss | 辅助 SF loss |
| --- | --- | --- |
| 编码器、router、entropy model、codec g_s | 正常更新 | 不更新 |
| SANA 第 1–8 层的已有可训练参数 | 正常更新 | 更新 |
| SANA 第 9–20 层的已有可训练参数 | 正常更新 | 不更新 |
| SANA 第 21–28 层、输出层与 VAE decoder | 正常更新 | 只作为冻结权重读出，对其输入保留梯度 |
| 训练辅助 P | 不参与主路径 | 更新 |
| EMA Teacher | EMA 更新，无反向 | 无反向 |

“冻结权重读出”不能用 `torch.no_grad()` 包住整个尾部，因为需要图像 loss 对 H_P 的输入梯度。可用 detached 参数的 functional call，或正确实现的无参数梯度读出。辅助 backward 期间不能原地更新共享权重；两条路径都 backward 完成之后，才执行一次 optimizer step。

这样图像 loss 直接检验 H_P 是否能被现有 C 解码器使用；同时避免受扰辅助视图直接训练 codec 的码率分配，或直接改变解码尾部去迁就一个不兼容的 projector。收益若存在，应通过前 8 层的实际表征学习以及后续正常 RD 联合训练体现。由于主 RD 仍在端到端更新，码率仍可能间接变化，梯度隔离不等于码率严格不漂移。

部署继续走完整原生 C。P、局部扰动与辅助读出均为训练用途。训练中共享前缀能否改善这条部署路径，必须由原生码流评测确认，不能由辅助支路表现代替。

## 6. 工程实现位置及双卡安排

建议在源纯 C 10K 权重上新建独立实验，不继承失败 SF 的参数轨迹：

`/data2/ls/checkpoints/ditic-50k-warmups/c_precision_v2_lambda16_C_joint10k_20261023/0010000.pt`。

源模型、optimizer、LR 进度和 EMA 按继续训练语义保留，新增 P 与 SF teacher 状态单独初始化。不能把它伪装成“原 SF run 无缝续训”。新 run 的 provenance 必须记录源 checkpoint、实际 FP16 精度、warmup 和新目标。

代码应从当前仓库的原生 `BTCodec` / C 路径实现，复用 `c_sana_forward` 的 capture/分段执行能力；不继续使用会注入残差的 `CQuantizationResidualCodec.repair_received`。

主要新增接口：

- codec 暴露接收端已恢复的 bottleneck 和单独的 synthesis 函数，主量化/熵模型数值不变。
- SANA 支持“第 8 层捕获”及“从第 20 层状态运行第 21 层以后”，没有 head 时保持原生 C 前向。
- 辅助 projector、cosine loss、带输入梯度的冻结尾部读出、明确的主辅两次 backward。
- 检查 checkpoint/RNG/DDP/EMA 恢复，统计主任务与辅助任务的实际梯度去向。

双卡用 DDP：每卡 local batch 4、accumulation 1，有效 batch 8，每卡各有 EMA teacher 前 20 层的副本。Teacher 每卡只处理辅助半批、每个样本一个原生视图；不再两次 teacher 前向做特征相减。主辅顺序前向与 backward，释放主图后再算辅助图，并使用 checkpointing。

辅助路径要穿过尾部和 VAE 的输入梯度，显存可能高于当前实现，不能据当前约 23 GiB 占用断言一定装得下。若双卡 local 4 不够，再使用每卡 local 2、accumulation 2，仍保持有效 batch 8。显存试跑前不能称为“已验证可开训”。

P 先在冻结 C 的条件下做短暂初始化验证，使用同图原生特征，避免随机 P 的图像梯度直接破坏已有前缀。此准备过程单独记录，不冒充新的主 C 更新。随后从 C 的 10K 全局步继续，辅助权重在约 2K 个主更新内从 0 升到 1；主训练继续使用原配置的六档独立均匀采样、512 输入、学习率与主损失。

## 7. 哪些证据出现后才值得长训

先做低成本、可推翻方案的检查：

1. **前向接线**：teacher=student 的起点，把真实原生第 20 层特征接入尾部，应重现该原生 C 的输出；加入/移除辅助模块也不能改变原生码流或原生 C 前向。
2. **目标有内容**：正确图片的 teacher 特征应比跨图片错配、空间打乱的特征更适合还原原图。全局 RMS 标量单独不能解释辅助重建。
3. **学习不是只有 P**：在冻结 C 的初始短检查中，确认 P 的读出可以学；正式短实验中，确认 SF 对共享前 8 层的梯度非零，并在未扰动的验证输入上带来可测变化。P 的 loss 降低不作为成功标准。
4. **梯度和计费**：SF 对 codec/router/尾部权重为零，对 prefix/P 非零；主 native rate 与量化符号不因 mask 改变。主辅只做一次 optimizer 更新，GradScaler 与裁剪覆盖合并后的梯度。
5. **真实收益**：先跑 2K–4K 个主更新观察两次原生 Kodak24 评测；必须看实际总 bpp 的 RD 曲线、低档和高档分别的变化，以及逐图配对差异。若仍仅辅助指标变好，原生曲线持续落后，不以“SF 先坏再好”为理由直接投入十几万步。

这里的 2K–4K 是是否继续投入的短实验，不足以证明最终收敛收益，也不能把一次小幅波动当成显著改善。

后续若做消融，关键对照是“同样扰动与辅助读出重建，但去掉 teacher cosine”，用于区分额外重建训练与 Self-Flow 对齐本身的收益；用户已经提供的纯 C 是另一个参照。还应报告增加的训练计算，不把有效 batch 一样说成训练计算一样。本次仅提出这些对照，没有启动任何实验。

## 8. 方法定位与剩余风险

方法假设是：在原码率预算下，用完整接收信息形成的、能通过 C 尾部解码的深层表征，监督受局部不确定性影响的浅层，能够提高原生解码的上下文利用能力。它不是恢复未发送随机细节的办法，也不保证高低码率同时提升。

低码率更可能从上下文与结构恢复获益；高码率首先要求保护已有精度，是否也获得收益需要实测。若 teacher 第 20 层本身无内容区分能力，或者 P 的辅助能力完全无法迁移到原生完整 C，方案应被否定或重新选择目标，而不是继续加辅助损失。

创新候选在于“同一码流预算下的局部预测 + 具有实际解码含义的浅深层监督”；8→20、EMA、较清晰 teacher 或压缩语义蒸馏本身均不是新点。尚未做全面的新颖性检索，不能宣称这是已成立的新论文方法。

相关原始资料及其对本方案的约束：

- [Self-Flow](https://arxiv.org/html/2603.06507v1)：恢复完整表征预测和局部/深度不对称；不照搬其生成成绩。
- [OneDC](https://arxiv.org/html/2505.16687v2)：其语义蒸馏服务于真实 hyperprior 解码条件，提示辅助表征应有压缩任务含义；这里没有采用其外部 tokenizer。
- [When the teacher has more bits，作者机构摘要](https://www.eurecom.edu/en/publication/8851)：高码率到低码率的直接潜变量匹配需要处理码率约束。本次只读到了机构公开摘要，不能据此复述其完整实验或声称复现其 VNLD。
- [DiT-IC](https://arxiv.org/html/2603.13162v1)：重建目标及可解码潜变量几何比生成模型中的抽象相似性更直接；这里不重新引入其 variance/timestep 后端或 repaired-latent loss。

上述文献支持设计动机，不证明本方案的有效性。
