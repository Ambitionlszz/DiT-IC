# C+SF 12K 码率漂移诊断

诊断对象：local_precision_v1，纯 C 10K 初始化，双卡每卡 4、积累 1，有效 batch 8，4/1/1 + 0.1 base + β(qA)R + SF。训练未被暂停或修改。以下分析区分完整 Kodak 评测、固定小样本诊断和结构性推断。

## 最新 14K 的效果边界

14K 完整 Kodak24 与外部纯 C 14K 对比：最低档码率 -9.03%、PSNR -0.2076 dB；最高档码率 +5.71%、PSNR +0.0225 dB。高低档工作点漂移仍在。

但在共同实际 bpp 区间的 101 点插值中，14K 平均 PSNR +0.00222 dB、LPIPS -0.000240、DISTS +0.000070，整体近乎持平。因此准确结论是“SF 尚未产生明确压缩收益，并存在增加码率的优化方向”，不能说所有指标已经明显恶化或长期必然失败。以下表示与梯度诊断固定在 12K，不冒充 14K 的参数测量。

## 结论与证据范围

已确认：高档增加的码率主要在主 latent 码流；正式单质量评测没有混合 mask 开销，header/allocation 长度不变。固定图像上量化平均步长不变，但高档编码 latent 和量化符号的幅度增加。SF 在 router 上与省码率目标存在明确梯度冲突，包括部署使用的原生单质量路径。

最符合证据的解释：SF 既能要求解码器更会恢复，也能奖励前端提供更易对齐的输入；后者可以通过增加传输信息实现。局部混合还改变了原 C 的条件 RD 任务。两者共同存在，尚无保持局部混合不变、只关闭 SF 的训练对照，不能拆分其累计贡献，也不能凭 12K 的小幅曲线差异宣布长期必然失败。

## 1. 完整 Kodak24 真实码流

外部纯 C 12K 与当前 SF 12K：q=0 码率 -5.90%、PSNR -0.1665 dB；q=1 码率 +4.66%、PSNR +0.0269 dB。六档在共同真实 bpp 区间插值比较：平均 PSNR -0.01315 dB，LPIPS +0.000645，DISTS +0.000639。没有显示压缩效率收益。

码流分量只能用本次实验自身的 10K→12K 分解，因为外部纯 C CSV 没有分量数据。最高档 total 从 0.09484185 增至 0.09936185 bpp；main 增加 0.00462850，hyper 减少 0.00010851；header/allocation 不变，mask/scales 为零。硬量化概率估计也同步增大，不能用额外 teacher 传输或漏计 mask 来解释。

## 2. 固定输入时，编码表示确实变了

前四张排序 Kodak 图片的 512 中心裁剪，冻结同一 VAE encoder，比较部署 EMA 10K/12K；仅为小样本，不是全 Kodak 分量评测。

| 项目，q=1 | 10K | 12K |
|---|---:|---:|
| 几何平均量化步长 | 0.5000 | 0.5000 |
| 编码 latent RMS | 0.89341 | 1.00890 |
| 量化符号 RMS | 1.39122 | 1.57459 |
| router allocation 标准差 | 0.17028 | 0.20575 |
| 主码流估计 bpp | 0.091176 | 0.095620 |

因此 q 控制步长，并不固定文件大小。固定步长下，编码器改变表示尺度和符号分布，仍然能多花 bits。router allocation 已去均值，不能把原因描述成“router 把全图步长都缩小”；它改变的是局部精度分配。最低档则呈相反趋势：latent RMS -5.01%、符号 RMS -6.31%、主码流估计 -11.04%。

## 3. SF 是否真的推动更费 bits 的方向

使用 12K raw student 和该 checkpoint 的 EMA teacher；两张固定 Kodak 512 中心裁剪，按正式机制一张原生、一张 25% 局部混合，CPU FP32，无优化器更新。各组分别比较 SF、混合输入 rate、原生单质量 rate 以及 base 的梯度。使用训练的 noise likelihood 和 STE，因此属于训练代理目标的一阶诊断，不能视作真实 ANS 字节数的有限差分证明，也不等价于 Adam 最终总更新。

下表第二列是 SF 梯度与原生单质量 rate 梯度在 router 参数上的余弦；负值表示单独沿 SF 的负梯度更新，会一阶增加原生 rate 估计。第三列分母是正式训练使用的 β(qA)×混合 rate 梯度。最后一列是 SF 沿编码 latent 整体放大方向的导数；为负表示训练代理梯度奖励放大。

| qA/qB | SF 对原生 rate 的 router 梯度余弦 | SF / 加权 rate 的 router 梯度范数 | SF 的 latent 放大方向导数 |
|---|---:|---:|---:|
| 0.0/1.0 | -0.927 | 0.019 | -0.012409 |
| 0.2/0.6 | -0.904 | 0.024 | -0.006713 |
| 0.6/0.2 | -0.910 | 0.315 | -0.000960 |
| 1.0/0.0 | -0.824 | 1.993 | -0.003698 |

四组都存在明确的 router 冲突；最高档的 SF 梯度约为加权 rate 的 2 倍，最低档约为其 2%。四组的 latent 放大方向也都能降低 SF，同时增加 rate 代理目标。这与高档表示放大、码率增加的实际观测一致，但不代表所有前端参数都强烈冲突：g_a 的整体梯度余弦接近零到轻微负值，最强冲突位于 router，不能扩大为“整个 encoder 都被 SF 支配”。

这解释了为什么“SF 权重是 1”仍可能改变各码率档的平衡。原 C 中，额外 bit 只购买重建收益；加入 SF 后，额外信息还可能购买对齐收益。β 不变并不意味着原来的压缩工作点不变。

## 4. 局部双质量改变了条件任务

实现中 qA 分析条件与全图 β(qA) 保持原先设置；半个 batch 的四分之一 coding cells 换成独立 qB。这是明确实现的训练定义，不是误把 β 读成了 qH。

但最高档 qA=1 可以局部换成 qB=0：局部变粗的输入也需要重建，而码率惩罚仍只有 0.5。最低档 qA=0 则可以夹入更细的局部，但整张图仍使用 β=16。qB 边缘分布均匀并不意味着条件 RD 任务与纯 C 相同。即使关闭 SF，混合 RD 自身也可能改变码率分配。这一点需要独立对照才能量化。

编码器分析只接收 qA，并不知道随机局部 mask，因此不能在前向中按这个随机 mask 精确补码；更一般的表示增益和共享精度策略改变，是一条可能的适应路径。

SF 有效参与也不对称：qB>qA 时四张图都参与，qB<qA 时只剩两张混合图参与；代码逐图先归一化再取 batch 均值，不应把 0.875/0.125 的有效位置比例误读为损失强度恰好相差七倍。最高档原生图没有更高档 teacher，SF 只由局部降质的图触发，其对正常最高档部署的帮助仍需迁移。

## 5. 不应重复沿用旧版诊断

当前 student 是一次完整 28 层前向，H8 来自正式路径，没有旧版专用 P 和跳层辅助出图，不能再归因于 P 吸收训练收益。当前训练也无数值重启，不能把本次 RD 漂移归因于 FP16 NaN。

当前小样本的 teacher 特征有内容与位置区分度。例如 qA=0/qB=1：正确图对齐损失 0.0523、错图 0.1692、空间反转 0.9872。该测试只说明对齐目标能区分内容，尚不能证明它对最终重建足够有用。也没有证据支持直接宣布特征塌缩。

## 6. 与原 Self-Flow 的差别及后续设计含义

原论文的双时间步通过固定加噪构造信息差，student 同时执行生成任务与特征对齐；它没有一个会因 SF 梯度而多发 bits 的可学习通信通道。将时间步替成可学习压缩前端的质量档后，这条额外优化通路出现了。

论文：https://arxiv.org/html/2603.06507v1

下一版首先应验证“给定同一份 C 码流，SF 是否提升恢复能力”。前端与 SF 的联动应最终体现为真实 RD 让编码器少传仍能恢复的信息；直接把 SF 梯度送入编码器/router，本身不能保证这种联动。单纯提高 rate 权重或调低 SF，可能只把工作点移回去，不能证明压缩能力提升。

后续若验证因果，最有区分力的两个对照是：保持局部混合与 RD 完全相同，仅关闭 SF；保持 SF 的输入/teacher/损失不变，仅切断 SF 到 codec/router 的梯度。这是建议的消融定义，本次没有额外启动训练。
