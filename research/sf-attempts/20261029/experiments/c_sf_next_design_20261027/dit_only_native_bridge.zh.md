# C 的原生压缩路径与 DiT 双视图关系学习

日期：2026-10-27。状态：计算取舍已确认；用户补充旧实验失效证据后，当前停在最终方案复核，尚未实施、GPU 预检、提交或替换训练。用户已明确接受每张图在正常完整 student 重建之外，额外计算一次混合输入的前 8 层。本次答复确认的是设计取舍，不代表已执行训练操作。

## 这次修正针对什么

旧实验的 P 与跳层辅助读出不在正式解码中，且 C 冻结时 P 单独就能降低对齐误差，因此旧对齐指标不能代表 C 的进步。新实验取消这套读出，同时对同一次正式重建中实际使用的 H8 加入 SF；混合前缀的关系目标也与它共用。

旧预检中正确/错图/空间打乱 H20 经辅助尾部读出后，D411 区分很弱。这不足以支持旧读出的 teacher 有用，但也不等于证明原生 DiT 的 H20 没有内容。新实验不再把较高质量 H20 插入另一种输入基底的解码状态；teacher 只提供空间关系，真实输入所需的修正仍由完整 student 在原图重建监督下学习。取消该错配不意味着 SF 与 RD 的梯度必然一致。

空间关系是否有帮助、是否被位置模板主导，仍是待验证假设。内容诊断只排除明显无效的目标，真正有用与否由短期原生 RD 试验决定；不把任一低 SF 数值、错图可区分或输出发生变化作为有效性证明。

## 要检验的主张

在保持 C 的真实码率—重建目标不变的前提下，让局部双质量观察与真实单码率观察，共同预测同一个 EMA DiT 的空间关系。混合观察负责局部上下文学习，原生观察负责将这份监督直接接到部署用的表示与 codec。

teacher 仅为 EMA DiT 前 20 层及必要的文本条件投影，不包含 codec、VAE、熵模型。当前共享 C 在不同 q 下提供输入，这一视图构造操作不是 teacher 的组成模块。

## 每次更新的前向

1. 保持源 C 的全局主质量 qa iid 六档抽样，所有四张按 qa 编码。得到 cA、原生 likelihood 与 side bits，保留 cA 的梯度。qb、局部 mask 使用独立且可保存恢复的 SF RNG，不挤占原有主质量/数据增强随机序列。
2. 同一原图 latent z 在独立抽取的 qb 下，经共享当前 C 构造 cB。这条辅助编码分支全部 no_grad，没有另一套 codec 权重。
3. 全图较高名义质量 cT=cA 或 cB，取决于 max(qa,qb)。teacher 接收 detach(cT)，输出 H20T 与关系目标，无图像解码。
4. 四张原生 cA 都完整运行 student DiT 第 1–28 层、原 CStep、VAE；读取这同一次前向的 H8native。计算原来的完整 C RD，以及原生关系目标。没有 P、跳层、残差注入或额外质量 conditioner，沿用源 C 的 DiT 结构。
5. 构造 cMix=(1-M)*detach(cA)+M*detach(cB)，M 先沿用 25% AE latent cells，每个 cell 的所有通道同步选择。qa/qb 不预先按高低分配给 M。对全部四张 cMix 运行共享 student 前 8 层，得到 H8mix，只计算关系目标，不运行第 9–28 层或 VAE。
6. 原生与混合两个 backward 累积到同一组 student 权重，一次 optimizer step，之后更新 EMA DiT。teacher 关系目标可在两种 student 输入之间复用。

相等质量抽样保留；可省去完全相同的混合输入前向，此时只保留同输入深浅层的原生关系监督，对有效视图取平均。不人为强制重抽成不同质量。

## 为什么不把混合视图也重建一遍

本版作一个明确取舍：生成重建由同一个 student 在真实原生输入上完成；混合观察只提供表征任务。因此没有 D_mix，也不将不具备对应原生 packet 的混合 latent 重建冒称为低 bpp 的真实 RD。

如果要求混合视图也完成生成，就应明确加入它自己的图像损失，并重新讨论额外计算与训练目标权重。完整跑混合 28 层和 VAE，却只在 H8 施加关系监督，不会让后续层得到该辅助任务的梯度，是无益的计算。

这与原文的 mixed 输入同时生成和对齐不同，不能声称完整复刻 Self-Flow。保留的是随机两档、局部信息不对称、更完整 EMA 视图与浅层到深层的自监督；新增原生关系监督是适配 C 的关键连接。

## 关系目标

每张图独立处理，H 为 N×D，空间中心化后计算 K=Hc@Hc.T。取 K 的非对角元素展成 r，并在 FP32 用数值稳定的 cosine 比较两个 r：

    Hc = H - mean_tokens(H)
    r(H) = off_diagonal(Hc @ Hc.T).flatten()
    d(H,HT) = 1-cosine(r(H), stopgrad(r(HT)))

    L_SF = mean_images[ mean_valid_views(
        d(H8native,H20T), d(H8mix,H20T)) ]

同一个目标既要求混合视图学会结构预测，也要求实际部署输入的 H8 具备这些关系；不依靠一个训练专用预测头拟合完整 teacher 向量。关系目标仍可能含无用纹理、位置模板或发生退化，不能把取消预测头当成有效性证明。

## 损失和梯度

    L_C = D411(x_hat_native,x) + 0.1*base(cA,z) + beta(qa)*R_native_total
    L = L_C + ramp(step)*1.0*L_SF
    D411 = 4*MSE + LPIPS + DISTS

base、beta 六档 [16,8,4,2,1,0.5] 与 source C 一致；repaired-latent loss 为 0。没有第二份图像损失，不对混合视图分配伪造的 rate，也不校准出 0.6413 一类 SF 权重。

- 原生图像重建：正常更新整个可训练 C。
- 原生关系：H8native 不 detach，可经过 DiT、g_s、量化 STE 和 g_a 到 codec；原生编码同时承受真实 rate/base/重建约束。
- 混合关系：输入 detach，只训练共享 DiT 前缀；不靠未计费的高质量局部输入直接优化编码器。
- teacher 与辅助 cB 构造：全部无梯度。无 EMA codec。

训练 rate 使用原生 likelihood 与所有 side bits 的估计，最终评测使用原生真实 packet 字节。辅助 qb 编码仅增加训练计算，不增加部署码流。

## 双卡与验证

从指定纯 C10K 完整 checkpoint 开始，继承主模型、评测 EMA、优化器与 LR 进度；512、两卡各 4、积累 1、有效 batch 8。四张全部原生重建、全部做原生 SF，再做额外混合 prefix8。每卡每次更新为：4 张完整 student＋4 张 mixed prefix8＋4 张 EMA teacher prefix20；teacher 不运行 VAE。不是每张图只有一次 DiT 计算，新增 prefix8 的成本必须如实报告；没有新增混合 VAE。若未来预检 4×1 不可行，按已确认的取舍回退每卡 2、积累 2。

从纯 C10K 的 raw student 初始化 teacher 的对应前缀，正式图像评测的模型 EMA 则继续继承 source C 的 EMA，二者明确区分。10K→12K 将 SF 从 0 ramp 到 1；第一阶段训练到总步数 20K，12/14/16/18/20K 做原生 RD 评测，14/16K 是观察点，不因早期一次回落就终止。teacher EMA 先沿用 0.999，原 C 的质量采样、优化器与 LR 保持一致。源 C 无新增 q conditioner；不继承旧 SF 的 P、辅助读出或已训练权重。

双卡采用数据并行：每卡各一份无梯度 teacher 前 20 层，各处理本卡 4 张。依次进行 teacher、原生 student 与混合前缀前向/反向，避免同时保留两个 student 图。先实际测量完整更新的显存峰值；teacher 可以分小批无梯度计算，若仍无法容纳，回退每卡 2、积累 2，维持有效 batch 8。沿用已验证的 V100 FP16＋敏感运算 FP32 实现；外部纯 C 的 BF16 差异仍是对照限制。

现有 c_sana_forward 支持无 head 的完整 capture 和 prefix stop；CResidualTeacher 内部只有所需 EMA DiT，名称不意味着要沿用旧 residual 任务。仍须完成 method/factory、checkpoint 与同步接线；尚未测试。

长训前需要确认：源 C 的原生重建等价、原生 SF 的 codec 梯度确实存在、混合输入与 teacher 无编码器梯度，以及 H20 关系含图像内容。对真实特征记录正确图、错图、空间打乱、跨图平均关系的差异，以及原生 H8 到 teacher 的起始差距、关系范数和样本间变化。它们只诊断明显退化或没有学习空间，不给训练目标加打分、梯度门控或新的损失。正确/错图可区分仍不能证明该目标对重建有用。

成败判断是外部纯 C 同 step、同真实总 bpp 下的低/中/高码率表现，只在 RD 曲线共同码率范围内插值，不外推。每次原生六档评测均记录全 Kodak24 的逐图实际 packet 总 bpp、PSNR、LPIPS、DISTS，并报告同质量档位的 bpp 漂移；不能用多发 bit 获得的画质提升冒充压缩收益。12–20K 看连续趋势；早期下滑不直接判失败，但到 20K 若只有 SF 好看、正式 RD 无持续收益，就不自动接 200K 长训。

SF 下降不算压缩成功；单 seed 的微小差异不称稳定收益。可先比较整个配方；进一步归因需相同训练但关掉混合关系或原生关系的短对照，不自行占卡启动新的纯 C。
