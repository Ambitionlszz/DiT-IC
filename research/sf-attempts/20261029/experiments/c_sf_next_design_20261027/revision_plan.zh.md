# C + Self-Flow 修改方案：让空间预测约束真实压缩路径

> 已由 `single_pass_design.zh.md` 取代：用户明确要求所有图片的重建与 H8 对齐复用一次完整 student 前向。下文两次 student 前向的建议仅保留为设计历史，不再作为下一次实验的执行方案。

日期：2026-10-27。状态：设计复核，尚未实现或进行本版 GPU 预检。本次没有切换、停止或启动训练。详细数学与已有失败证据见同目录 `design.zh.md`；本文件给出本轮的实施取舍。

## 核心判断

当前结果没有建立 C+SF 优于 C 的证据。已核实的 18K 对比，在重叠的真实总 bpp 区间内插值后，平均 PSNR 约 -0.018 dB，LPIPS 约 +0.00080。这是小幅劣势，一个 seed、Kodak24，不能当作统计显著性结论。

代码中可确认的脱节是：SF 使用 detached codec 输入，执行 1–8 → P → 21–28 的辅助读出；实际部署执行完整 C，且不使用 P。辅助任务变好不等于实际完整路径得到改进。公共分量使 cosine 过于容易、teacher 空间结构是否更有用，仍属待测假设。

本版只检验一个主张：**让真实低码率表示在浅层学到高质量深层 teacher 的图像内空间关系，同时始终接受真实码率和图像重建约束。**

## 一个模型，两种 student 输入

沿用源纯 C 的完整架构，不新增 SANA 六档质量 conditioner。保留原 codec 已有的 precision-v2 conditioning。

1. 原生视图：按纯 C 的方式 iid 抽 q，得到真实 codec 解码 latent c_q，运行完整 1–28 层与 VAE，计算原始 RD；读取这一前向的 H8。
2. 局部视图：每卡随机选半个 batch，独立抽 q_b，并运行 q_b 对应的独立 codec analysis；在 25% latent 单元替换为 c_qb，得到 c_mix。q 和 q_b 不排序，允许相等，单元内所有通道一起替换。
3. c_mix 也运行同一个完整 1–28 层与共享 VAE，重建同一原图，并读取 H8。使用混合输入自己作为 C scheduler 的基底。取消 P 和专用的跳层读出。
4. teacher 使用 EMA codec 与 EMA SANA 前 20 层，观察 q_H=max(q,q_b) 的完整均匀质量输入，输出 H20。teacher 包含产生该目标所需的可训练模块，全程 no_grad；冻结 AE 可共用，teacher 无需 VAE decoder。

这样保留两种非对称：student 内部的局部精度差；浅层、信息较少的 student 与深层、名义质量较高的 teacher。q_H 是质量控制值，不声称每张图片的实际码率和质量严格排序。

混合输入仅是训练视图，不把两个独立 codec 的 latent 拼接说成一份真实混合码流。实际压缩、解压和计费始终走原生视图。

## 监督什么

不再用 P 拟合 teacher 的整条原始向量。直接从 H8 和 H20 提取每张图的空间关系：

    Z(H) = H - mean_tokens(H)
    K(H) = Z(H) Z(H)^T / (mean_i ||Z(H)_i||^2 + eps)

K[i,j] 描述两个位置的特征关系，不要求不同深度采用相同通道坐标。计算用 FP32。不按微弱通道逐个除方差。

去掉对角线，在监督行 Ω 上计算相对关系误差：

    d = mean_(i in Ω,j!=i) (K(H8)[i,j] - stopgrad(K(H20)[i,j]))^2
        / stopgrad(mean_(i in Ω,j!=i) K(H20)[i,j]^2 + eps)

原生视图对所有行计算；混合视图只对相对 teacher 名义质量较低的那些位置计算。这些位置与全图其他位置建立关系，保留从较清楚上下文补偿受损区域的任务。

若 q=q_b，则混合关系项为空，仍保留原生的深度不对称和图像重建。每张选中图片对有效关系项取平均，再对图片取平均，得到 L_rel。

这个目标对通道正交变换不变，去除空间公共平移，对整体正缩放近似不变；不对任意可逆变换不变。它不能唯一确定图像，不能保证只保留语义、自动忽略所有不可恢复纹理，也不能防止纯位置关系成为捷径。颜色、内容身份、细节仍由原始 RD 约束。

若 teacher 的有效空间能量贴近数值噪声，不能靠归一化把它放大成监督。删除 P 也不等于严格防止退化：EMA teacher 自己变得简单同样会降 loss，必须检查 teacher 的内容差异和有效秩。

## 目标与梯度

    D411 = 4 MSE + LPIPS + DISTS
    L_C = beta(q) R_total + 0.1 base + D411_native
    L = L_C + ramp * (L_rel + D411_mix)

SF 外层权重固定 1，不做梯度匹配校准。beta(q) 保持 [16,8,4,2,1,0.5]；base 定义不变；repaired-latent loss 为 0。辅助图像项也是 4/1/1，按选中的半 batch 求均值，不另乘 2。

- **原生 SF 不 detach codec 输出**：约束沿原 SANA 前 8 层、g_s、量化 STE、g_a 及相应可微路径回到实际压缩表示；这份表示同时承受原始 R_total、base 和最终图像失真。
- **混合输入 detach**：混合关系项训练共享前 8 层；混合重建训练共享完整 SANA 和 VAE。第二份辅助编码器不靠未计费的混合任务梯度更新。
- teacher 全部 stopgrad，EMA decay 先沿用 0.999。

原生码率项是软约束，不保证同 q 不涨 bpp。是否改善“有限 bit 保留什么”，只能通过同真实总 bpp 的曲线验证。

辅助重建增加了训练计算和图像监督量。因此，纯 C 对比只能判断整个配方是否有收益；若要证明收益来自 SF，需要相同混合重建、仅关闭 L_rel 的对照。本方案不自行启动用户已明确不需要的本地纯 C 训练。

## 配置与执行顺序

- 从上传的源纯 C 10K 完整 checkpoint 重开，不接失败 SF 的权重。恢复主模型、优化器、EMA、LR 与样本计数。
- 512 输入；双卡每卡 4、积累 1，有效 batch 8；若真实 teacher+student 预检 OOM，则每卡 2、积累 2。
- 两卡各有完整 student 与冻结 teacher 副本；不把某一张卡专门给 teacher。
- 每步先准备 teacher 目标和 detached 混合视图；原生完整前向与 backward 后释放激活；再混合完整前向与 backward；最后同步梯度、只做一次 optimizer step。
- 从 10K 起沿用 2K ramp，到 12K 达到外层权重 1。无需预测头准备阶段，无需重新加 10K 纯 C warmup。
- 六档 iid 采样、LR、有效 batch、4/1/1、base 与纯 C 一致。V100 保留现有 FP16 AMP 和 FP32 敏感计算修复，如实记录与源 BF16 的差异。

删除预测头不会自动抵消新增完整混合重建的显存开销。本版尚未实测，不能沿用当前版本约 23 GB 的占用保证 4×1 一定装得下。

## 先证实目标有内容，再决定长训

这部分是研究验证，不是额外用户审批。

1. 在固定预留图像上，检查 H20 中心化后的能量、有效秩、不同图片之间的关系差异，以及 FP16/FP32 的数值误差。正确 teacher、错图 teacher、空间打乱 teacher 都要比较；若只是稳定的位置模板，本目标不成立。
2. 直接测源 C10K 的 H8/H20 关系差距。若该目标已近乎满足，或差距主要是数值噪声，就不把它作为下一次长训候选。损失变难本身不是有效性证据。
3. 分别检查原生与混合监督的梯度归属，确认原生 SF 真正到达 codec、混合任务不更新辅助 codec、teacher 无梯度；观察 SF 与 RD 的梯度方向和尺度，先诊断，不加入梯度投影等额外机制。另在完整原生 C 中对实际 H8 的空间内容做干预，检查最终输出是否使用这条内容路径；不再用跨基底的跳层读出替代这个检查。梯度非零、图像变化非零都不单独构成收益证据；没有 P 也仍可能在主网络里学出下游不使用的表示。
4. 完成真实 512 双卡 forward/backward 与保存恢复检查后，先从 10K 短试到 14K/16K。比较低、中、高码率及完整六档同总 bpp 曲线；若只有 L_rel 降低、teacher 退化或 RD 持续恶化，不直接押注 200K。
5. 若短试出现稳定趋势，再扩到 20K/30K，并验证相同混合重建但关闭关系项的对照。已有纯 C 作主对照，不擅自占卡重跑纯 C。独立验证集用于选择方案，最终测试与选择数据分开；记录额外训练计算，不能把一个 seed 的小差异称为稳定提升。

## 切题之处与论文来源

不是声称发明了 Gram、EMA 或高码率蒸馏；这些均有先例。本方案要检验的是，局部双精度预测是否能在真实熵码率约束下改善实际使用的表示，而不是只让训练专用分支学会对齐。

- Self-Flow：保留局部信息差、浅层对深层、完整 student 主任务。https://arxiv.org/html/2603.06507v1
- iREPA：空间结构与空间归一化的研究动机；其生成实验不能替代本系统的 RD 验证。https://arxiv.org/html/2512.10794
- DINOv3：Gram 约束图像内 patch 关系，允许通道表示变化；本方案不是照搬其训练配置。https://arxiv.org/html/2508.10104v1
- OneDC：蒸馏所改善的条件来自已解码信息，并参与实际重建；启发这里检查实际使用与真实计费的联系。https://arxiv.org/html/2505.16687v2

这个版本比当前辅助路径更适合检验“C+SF 是否能超过 C”，但尚不能承诺高、低码率都会提升。若 teacher 本身缺少可用的空间结构，下一步应否定这项假设，而不是继续改 loss 数值或延长训练。
