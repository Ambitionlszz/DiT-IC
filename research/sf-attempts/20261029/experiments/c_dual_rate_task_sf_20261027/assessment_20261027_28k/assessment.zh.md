# 当前双质量任务版 SF 的收益评估

当前结论：尚未证明有实用压缩收益。28K 同总 bpp 平均 PSNR +0.01443 dB、LPIPS -0.000111、DISTS +0.000241；六档平均验证 RD 相对纯 C 改善约 0.10%。这是单次 Kodak24 均值比较，不是显著性或 SF 单独贡献的证明。

## 最有证据支持的解释

1. 辅助任务与部署路径存在结构差异。主路径为 1–28 层；辅助路径为前 8 层、约 531 万参数的 P、21–28 层。P 不参与部署，第 9–20 层也不接受该辅助任务的直接图像梯度。前 8 层及共享条件模块确实收到辅助梯度，因此不能说辅助完全无法影响重建；可疑的是转移效率和收益是否被 P 吸收。
2. teacher 目标的任务有效性没有通过强检验。启动时正确 teacher、错图和空间打乱目标对 D411 的影响很小；错图减正确平均 +0.0001386，打乱减正确平均 -0.0002004。预检阈值仅证明内容会影响输出，没要求正确内容显著优于错误内容。该诊断只在启动小样本上做过，不能据此断言 28K 同样如此。
3. cosine 降低不是完整重建受益的证据。P-only 准备阶段 C 完全冻结时已可取得低对齐误差；正式训练后 cosine 降至约 3e-4，部署 RD 仍接近基线。公共分量支配、梯度被 P 吸收等解释需要真实特征与逐损失梯度测量，当前尚未证实。loss 的数值比例不能直接当作梯度比例。
4. 高质量 teacher 的完整特征未必对应混合输入所需的修正。C 的更新是 c - sigma*v。teacher 的特征服务于较高质量 c_H，辅助读出却用 c_mix 作为基底、混合质量条件和当前 student 尾部；把特征变得像 teacher 不保证使这条读出的图像更好。其图像辅助损失也可能与 cosine 目标存在张力，尚未量化梯度方向。
5. SF 对付费表示的作用是间接的。辅助 codec 视图 detach，辅助不更新 codec/router；它必须先通过共享后端改善真实 RD，再由主 RD 改变编码。此路径有效与否尚未得到编码干预实验证明。直接开放 SF→codec 也没有必然收益，可能增加冗余与 bpp。

## 判断与下一步

不建议仅因对齐 loss 下降而继续长训至 200K。原定 30K 可作为本轮评估点。优先在保存后的当前 checkpoint 上做固定输入、尾部与质量条件的 teacher 小步插值/正确错图打乱干预；再做固定共享主干、仅更新 P 的短诊断以及 cosine/辅助图像/主 RD 的逐项梯度分解。若 teacher 建议本身不能降低真实 D411，优先更换目标；若 teacher 有用但只改善 P 支路，则优先修正收益向完整部署路径的转移。更换关系损失、提高权重、开放前端梯度均需这些证据支持，不能当作已知修复。

本次只读取代码、已有日志及验证记录，并保存分析。没有运行新的 GPU 诊断或修改训练任务。
