# 当前 checkpoint 判断与双卡 Self-Flow 对比建议

2026-10-22，Asia/Shanghai。用户已明确：双卡主比较为“现有 Self-Flow 对比改进版”。本文件是可供实施的实验规格，尚未修改训练器、启动训练或验证新方法收益。

## 1. 当前权重足以作为试验起点，但尚不能称为完全收敛

核查的是本机 `bt_self_flow_v1` 的新前端 C/D，未把 5090 的低码率 C 配方或尚未实现的 q 条件 Router 当作现有模型。

| 项目 | C | D |
|---|---:|---:|
| 最后保存的 train log | 89.2K | 90.5K |
| 最新完整 Kodak24 验证 | 88K | 90K |
| 最佳综合验证 | 86K | 90K |
| 80K 平均验证 RD loss | 0.321414 | 0.316962 |
| 最新平均验证 RD loss | 0.320648 | 0.316259 |
| 相对 80K 变化 | −0.238% | −0.222% |

两组均未启用 SF，之前还有共同 50K codec warmup。D 在 80K→90K 的固定实际 bpp=.04/.06/.08/.10 上，PSNR 约增加 .066/.077/.073/.072 dB；感知指标有改善也有波动。应称为慢收敛、边际收益变小，不能将综合 loss 平缓解读为所有图像指标都不再变化。

双方同为 88K 时，D 相对 C 的 PSNR/LPIPS/DISTS BD-rate 为 −2.13%/−4.39%/−4.15%。D/90K 相对本机旧 30K baseline 为 −5.82%/−13.71%/−20.32%；相对历史 200K baseline 仍为 +24.72%/+13.30%/+4.27%。后者训练预算、初始化与损失不同，仅表示当前差距，不能据此判定结构优劣。

这些结果来自已有 EMA 验证：Kodak24 原图、六档、完整实际 packet bpp、FP32 硬前向画质；每档两张真实解码检查误差为零。本轮没有重新执行全量真实解码。当前执行环境 CUDA 不可用，因此也未宣称已核验两张物理卡的实时空闲状态。

建议固定 D 的 90K 权重作为两组共同起点。不要一组从 C 出发、另一组从 D 出发。无需等待 D 跑完 200K 才验证辅助机制，但当前试验属于晚期端到端微调，不能替代从共同初始化开始的正式 200K 实验。

## 2. 旧 SF 的下降与恢复是真实记录，恢复后的净提升仍需对照

旧 A 为正常输入重建、另外混合视图对齐；旧 B 用混合视图同时重建与对齐。A 不是 RD-only 控制。

| 旧实验 | PSNR 最差点 | 恢复过程 | 归档最后结果：PSNR/LPIPS/DISTS BD-rate |
|---|---|---|---|
| A | 6K：+6.868% | 主退化后约 22K 再越过起点 | 50K：−0.870%/−0.206%/−0.128% |
| B | 8K：+5.458% | 主退化后约 24K 再越过起点，随后仍有波动 | 36K：−0.577%/−0.202%/−0.598% |

用户此前附图中的 B 延伸到 42K，本机原始数值归档只到 36K，本次不补造 38K–42K 数值。三项指标并非同步恢复；例如 A 的 DISTS 在 42K 仍出现回退。

据此，5K–10K 用于判断数值、监督覆盖和接入冲击，不宜作为最终胜负窗口。主实验建议两组各新增 50K，按 10K/20K/30K/40K/50K 比较；若后期已形成清楚稳定的排序，可以在共同节点结束。数值异常、错误码流或几乎零有效监督应立即诊断，不以“SF 本来先差”作为继续无效训练的理由。

原论文报告不同任务下的收敛优势，并没有将接入已训练压缩模型后必须先大幅退化定义为规律。跨层目标改写、优化器重启、教师滞后、辅助梯度与重建梯度冲突都是待排查原因，现有曲线未证明某一项是唯一根因。

## 3. 双卡主对比：同一个 D 起点，一张卡一组

本轮原版指当前 BT 训练器中的跨码率 Self-Flow 机制；它与旧 A/B 不是同一个前端或完全相同的训练实现。两组独立单卡训练，不把一张卡固定当 teacher、另一张当 student，也不对两种方法做 DDP 梯度平均。

| 项目 | GPU 0：现有 BT Self-Flow | GPU 1：改进版局部干预 SF＋分配反馈 |
|---|---|---|
| 学生主重建输入 | 现有正常/混合交替，混合时 25% 位置用 q=1 | 始终为正常 Router、正常全局 q 的可部署输入 |
| 教师信息 | 全图 q=1 的视图 | 同 q、两种互补局部分配视图 |
| 对齐 | 现有 student_layer=8、teacher_layer=20 与 projector | 同层 12/12，2×2 SANA token 池化，无新增 projector |
| 可靠性 | 现有粗误差优于学生的门控 | 同时核对粗误差与最终图像区域误差 |
| 损失归一化 | 现有除以有效位置权重总和 | 除以全部块数，稀少目标自然减弱 |
| SF 梯度 | 保留现有训练器路径 | 仅 DiT LoRA/尺度条件；前端由 RD 更新 |
| 新 Router 信号 | 无 | 完整 RD 代价下的局部精度交换方向 |
| 教师 EMA | 现有 .9999 | 首试 .999，与 deployment EMA 分开维护 |
| 辅助接入 | 现有 1K warmup＋2K ramp | SF 与 alloc 共用 0→3K ramp |
| 更新预算 | 新增 50K | 新增 50K |

层号以代码现有零起点索引为准。此表比较两个完整训练配方，无法单独把胜负归因于层号、EMA 或分配反馈；获胜后需要拆项消融。新方法保持源 D 的主结构，不在本轮同时加入 q 条件 Router、新 ga/gs 调制或修改图像损失。

### 共同优化安排

推荐从 `/data2/ls/checkpoints/bt_self_flow_v1/D/joint/0090000.pt` 中的 deployment EMA 导出同一份起始学生，两组完整复制 codec、Router、DiT LoRA、尺度条件、VAE decoder LoRA、文本投影和必要缓冲区。这样 0 步推理与已验证 D/90K 对得上。每组教师从自己的 0 步学生完整复制；不能只复制 LoRA 而遗漏尺度条件/文本投影。

两组都新开 AdamW，主参数共同 500 步学习率 warmup，之后相同 cosine 日程到峰值的 10%。共同重启优化器属于实验设置，需要披露；也正因此还应补 RD-only continuation。若实现改为保留源优化器动量，则两组必须同时改用相同 raw 起点、保留同样状态，并另外验证各自 raw/EMA 的 0 步行为，不能混搭两种初始化协议。

主参数峰值以源 D/90K 实际学习率的 .2 倍为首试值，而非突然回到源初始峰值：

- codec/Router：约 `6.22e-6`。
- DiT LoRA、尺度条件、文本投影：约 `1.24e-5`。
- VAE decoder LoRA：约 `1.24e-6`。
- 熵模型 quantile 的独立 aux optimizer 沿用原设置，两组一致。

这组数值来自原 cosine 日程公式，属于保守初值，尚未实测最优。两组有效 batch 都为 8，优先保持 microbatch=2、累积4；如改进版显存不够，可两组共同改为 microbatch=1、累积8。固定相同图像顺序、增强和基础 q 抽样；教师/区域采样使用独立随机数流，避免额外随机操作改变主训练样本。

两组保持原 RD 目标：`2*MSE + LPIPS + .5*DISTS + .1*base + .1*latent + beta(q)*rate`，`beta(q)=8*32**(-q)`。q 仍在 [0,1] 均匀采样，编码步长、原生 SANA 时间、残差公式、训练模块和部署 EMA 规则保持一致。

## 4. 改进机制：让一次真实局部干预同时教恢复与分配

### 学生输入和干预

每个 update 都先用正常全局 q、原 Router 分配码 c 完成一次原 D 的 RD 训练。首试每两个 update 做一次 probe，从第一步开始固定采样；这是对先前 200K 方案每四步 probe 的短程试验调整，用更多有效观测换取算力。不能在实验中根据 Kodak 结果任意改变频率。

每图选择两个不重叠、同样大小的 2×2 编码区域 A/B。所有被改码值须在 1…6，确保可双向移动；没有合适区域就跳过辅助，不裁剪成不对称干预。构造 `c+ = c + 1_A - 1_B`、`c- = c - 1_A + 1_B`。

源代码分配量为 `a=2*c/7-1-mean(2*c/7-1)`，所以提高一码会让该区域步长约乘 `2**(-2/7)=.820`。两区域同样大使码值总和不变，其他位置的中心化分配不变；实际主码流 bpp 仍可能不同，不能称为严格等码率教师。

共享停止梯度的同一次在线 codec 分析结果，两份候选分别重新执行量化、四轮上下文、LRP、gs 与自己的实测/量化尺度。禁止拼接两份已经恢复的 coarse latent。两份候选用同一时刻的完整 EMA DiT＋EMA VAE decoder 解码，捕获层12特征；两次教师前向顺序执行。教师不反传。

### 局部 Self-Flow

在 A 取 + 视图、B 取 − 视图。只有候选的粗 latent 误差和对应最终图像区域误差均优于正常学生时，才提供特征目标；粗误差首试要求超过 5% 相对优势，最终图像 MSE 也必须严格下降。最终像素块按编码网格映射，门控值全部停止梯度。

双方层12特征按2×2 token平均池化后 L2 归一化，用有界相对粗误差优势权重计算 cosine loss；除以全部块数 N，不除以有效块数。粗误差门控和局部像素门控都只是可靠性近似，不能保证感知指标受益，故仍须观察 DISTS/LPIPS 和独立图像。

特别要记录有效位置占全部网格的比例、按 q 分桶的覆盖、辅助梯度 norm 与特征跨图/跨位置方差。两块2×2区域在512裁剪上最多覆盖12.5%网格，再乘probe频率与门控后监督会更稀疏；若长期几乎没有有效目标，属于此配方的信息不足，不能只报SF loss变小或放大系数填满梯度上限。

SF 梯度首试校准到共享后端 RD 参数梯度范数约2%，probe更新上不超过5%，之后只允许减小，不追逐稀少目标。校准基于多个有代表性的训练批次，而非在 coarse latent 上比较梯度。RD正常反传；SF限定参数集合求梯度后合并，不detach学生RD的coarse路径。

### 分配反馈

用同一套 EMA 后端与源 RD 失真权重，计算两候选全图代价 `J+ / J- = D_task + beta(q)*R_total`。D_task 包括原图像及 latent/base 项，R_total 包括主码流、hyper、allocation、尺度和头部。训练probe可用原likelihood加完整固定侧信息估计；定期用真实packet核对排序，不每步执行rANS。

设 rA/rB 是量化前连续码值在区域内的均值，h=1。使用停止梯度方向 `d=(J+ - J-)/(2*h)`，代理损失 `L_alloc=.5*stopgrad(d)*(rA-rB)`。当+视图更划算时推动A相对B优先级上升，反之下降。对代价差做训练校准得到的有界截断，数值/码率估计不确定范围内的近似平局不给反馈。

该项只直接更新 Router，原 Router 的 RD 梯度继续保留。alloc 首试也是 Router RD 参数梯度约2%、probe更新上限5%，与SF共用3K ramp。它是基于硬量化观测构造的方向代理，没有精确梯度或无偏性保证。

研究中心是：当前生成后端还能从哪些额外编码证据受益，同时影响恢复目标与分配决策。普通端到端RD也在优化分配，必须以额外收益证明干预反馈的必要性；不能仅以空间热力图或使用SF名称作为证据。

当前Router本身不接收q，参考成本也使用固定中间步长。因此本轮分配反馈只能学习跨q平均更划算的策略，不能声称实现了随q变化的分配。若不同q的偏好长期相反，应将其记录为该固定结构的表达限制，不能以增大alloc权重处理。后续正式方案可将q条件作为两组共同的前端改动，用零输出残差接入并验证初始函数一致，再单独比较SF；本轮不混入这个额外变量。

## 5. 观察节点、成功标准与补充对照

前10K每500步用固定小验证集看raw与deployment EMA；完整六档Kodak24仍每2K一次。额外保存0、1K、2K、4K、6K、8K、10K和之后每5K的关键诊断。计算图/数值故障立即修复；初期小幅退化保留既定预算观察，但若同码率明显退化且梯度方向持续冲突，应检查辅助机制，不默认多跑必定恢复。

不要只比较相同q或单个最优checkpoint。对每个共同更新节点报告：

- 真实全部字节bpp下的PSNR/LPIPS/DISTS、共同质量区间BD-rate，及固定bpp=.04/.06/.08/.10的变化。
- 相对0步的收益、最差退化幅度、从主退化后重新越过起点所需更新数，以及最后多个checkpoint的持续收益。
- 图像曝光量、累计GPU时间、峰值显存；增加等GPU时间比较。probe/教师计算必须计费。
- 按质量档的教师优势、有效覆盖、尺度饱和、Router边界饱和、SF/RD和alloc/RD参数梯度比与cosine；记录更新变化以辅助解释，不能把梯度比等同于Adam实际更新比。

本轮两张卡可以直接比较两个SF配方的最终效果与恢复速度；还不能证明任何一个比“继续训练”更有净收益。主对比完成后至少补同起点、同学习率、同重启规则的RD-only continuation；5K–10K只能检查优化器重启冲击，最终净收益需要与主要结论对应的共同训练预算。历史D的90K之后原日程不等同于本轮小学习率控制。

如果改进版显著胜出，再做“只有局部SF”“只有分配反馈”“二者联合”的消融。只有联合超过两项单独使用，才支持共同适应的主张。最终在未用于调参的独立测试集复核，并重复种子；本轮单种子Kodak结果只能筛选方案。

建议把有价值收益的目标预先定为：跨多个后期节点、主要工作码率段存在稳定优势，至少一个感知BD-rate改善达到约1%–2%，同时PSNR没有不可接受的代价。这个幅度是筛选目标，既不是预测，也不是统计显著性阈值；最终仍看逐图差异、复现与预算。

## 6. 当前代码需要补的接口

现有训练器的SF阶段要求源joint阶段完成200K，因此D/90K不能直接用原`--init-checkpoint`接入。需要正式支持固定中间checkpoint分叉，记录源文件哈希、源步数、权重种类和新训练日程；不能手改checkpoint的完成步数冒充已完成。

当前模型限定student_layer<teacher_layer并创建projector；新方案需要同层、无projector选项。完整教师还须支持末端输出和VAE EMA，现有截断层20教师不足以生成J。量化接口需合法allocation override、返回连续Router码值，并确保compress序列化的是覆盖后的真实码值。

现有SF直接加进总loss、在coarse上做梯度校准、按有效块归一化，均需为改进版增加明确路径。单卡可降低实现复杂度，但仍必须正确处理AMP、梯度累积、梯度合并与裁剪。启动前验证零步输出、干预码流与forward/decode一致性、梯度归属、参数/缓冲区完整EMA同步，并做两组相同有效batch的短步显存和耗时检查。
