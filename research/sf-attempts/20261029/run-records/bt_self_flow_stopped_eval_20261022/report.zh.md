# 旧 C/D 停止后的完整图真实码流评测

C：95,542 步；D：96,750 步。均加载停止时 paused.pt 的 EMA。

Kodak24 原尺寸完整图、六档、FP32、全局一次 SANA 解码。真正序列化后再从包解码，bpp 计入所有包头和分配图。
指标与已有 512 评测脚本使用同一实现：pyiqa PSNR/MS-SSIM/DISTS，torchmetrics LPIPS alex。历史 200K baseline 使用已归档的全局解码结果，本次没有重跑 baseline。

## 收敛趋势

- C：80K→94K，六档平均验证 loss 0.321414→0.319243（-0.68%）；0.06 bpp 插值 PSNR 24.1808→24.1312 dB，LPIPS 0.116063→0.114335，DISTS 0.064551→0.062841。
- D：80K→96K，六档平均验证 loss 0.316962→0.315528（-0.45%）；0.06 bpp 插值 PSNR 24.1326→24.1659 dB，LPIPS 0.113251→0.112448，DISTS 0.063111→0.062845。

这些曲线表现为趋于平台，感知指标仍缓慢改善；不能据此保证达到数学收敛，也没有证据表明继续到 200K 会自然追平 baseline。

## 码流中的 Router 分配

- C：主要编码值 5 占 76.35%；完整计数 [0, 0, 0, 17, 433, 1759, 95, 0]。24/24 张图的分配图在六个 q 下完全相同，与旧 Router 没有 q 条件的实现一致。
- D：主要编码值 3 占 78.95%；完整计数 [0, 0, 270, 1819, 214, 1, 0, 0]。24/24 张图的分配图在六个 q 下完全相同，与旧 Router 没有 q 条件的实现一致。

编码值本身经过逐图去均值后才转换成局部步长；主要编码值不同不代表全局步长发生偏移。分配是否有价值不能仅靠使用档位的多少判断。

## 解释边界

- C/D 停止步数相差 1,208 步，结果代表这两个停止时模型，不能当严格同训练步数的 D 消融。
- 旧 C/D 使用 2×MSE+LPIPS+0.5×DISTS，并有 0.1 base/0.1 repaired 辅助项；历史 512 使用 4×MSE+LPIPS+DISTS。训练目标与训练预算不同。
- GPU 推理与新 warmup 并行，时间数据不能用于速度排名。新训练没有被停止。
- 完整逐图码流与代表性 PNG 归档在 real_packet_results.tar.gz；全部 PNG 另保留在本机 /tmp/bt-stopped-real-packet-results-20261022.tar.gz；逐图指标、曲线及 BD-rate 积分区间保存在本目录。checkpoint SHA256 见 C/summary.json 与 D/summary.json。
